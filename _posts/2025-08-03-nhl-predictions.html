This post is a concise overview of the NHL prediction project and links to the full report, project summary, interactive app, and repository.

Project Summary

This project compares several machine learning approaches for NHL game prediction, including GLM, random forest, XGBoost, neural networks, and an ensemble model. The emphasis is on prospective evaluation, calibration, and practical decision-making using bookmaker and engineered game-level features.

Key Takeaways

  • Ensemble modeling improved performance over individual base models.
  • Calibration and prospective evaluation were central to the workflow.
  • The project includes a standalone report, a summary page, and a live app.
